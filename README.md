 Ireland's healthcare waiting list crisis is one of the most pressing public health challenges facing the country. 
 This project analyses real government data from the National Treatment Purchase Fund (NTPF) to uncover patterns, identify the most critically underperforming         hospitals, and forecast future demand.
 Using 25 months of real Irish government data covering 44 hospitals from January 2024 to January 2026, 
 this project delivers actionable insights through a complete data analytics pipeline — from raw SQL data engineering through to machine learning forecasting and      interactive Power BI dashboards.
